Finder Menu Tools is an **unofficial maintenance fork of [MenuHelper by Kyle-Ye](https://github.com/Kyle-Ye/MenuHelper)**. Credit for the original Finder extension, design and core functionality belongs to Kyle-Ye. This fork makes a few small usability and reliability fixes; it is not an upstream release or an endorsed successor.

### Download and install

Download **FinderMenuTools-4.0.1-macos-universal.zip** below, extract it and move **Finder Menu Tools.app** to Applications. The app includes Apple silicon and Intel executables and requires **macOS 15 or later**. Xcode and a developer account are not required.

This free build is **ad hoc signed and not notarised by Apple**. If macOS blocks it, use the app-specific **System Settings → Privacy & Security → Open Anyway** flow described by [Apple](https://support.apple.com/en-us/102445). Managed Macs may prevent installation.

Open the app, enable **Finder Menu Tools Extension**, then use **Settings → Folder → User Selected Directories → Add Folders** to authorise your home folder or selected folders. Configure the apps and actions you want in **Settings → Menu**. Remove the old App Store MenuHelper or previous MacMenuHelper app first to avoid duplicate extensions.

[Complete installation instructions](https://github.com/byrondelgado/MacMenuHelper/blob/v4.0.1/docs/INSTALL.md)

### Small fixes in this fork

- Open the Settings window directly from a Finder menu.
- Remove individual entries from either folder list with a visible minus button.
- Enable or disable each application with a clear on/off switch.
- Apply menu changes to Finder without a restart or a refresh-notification loop.
- Populate the first Finder menu immediately after extension startup.
- Restore folder-permission controls in Settings.
- Detect Warp and Visual Studio Code when installed; copy file and folder paths with a literal-path default.

### Validation and limits

The maintenance functionality was tested on Apple silicon with macOS 26.6.2: file/folder Copy Path, opening VS Code, Warp handoff, individual folder removal, persisted permissions, live application disabling, and the Finder Settings shortcut with the app closed and running. Universal binaries, code signatures, licence contents and archive checksums are checked during release preparation. Intel execution and first-time installation of a quarantined download on a clean Mac have not been tested. Upstream Swift concurrency warnings remain; the inherited screenshot UI test suite was not run.
